### Outline

1. **Introduction**
   - AI automation costs depend on workflow complexity, not just the technology used.
   - Some businesses need a simple chatbot; others need multi-step automation across several systems.
   - This guide explains what shapes cost and how to evaluate automation investment.

2. **What Shapes AI Automation Cost**
   - Workflow complexity and number of automation steps
   - Third-party integrations and API connections
   - AI model requirements and prompt engineering depth
   - Data access and security requirements
   - Testing scope and edge-case coverage
   - Deployment environment and ongoing maintenance

3. **Typical Scope Ranges (Conceptual)**
   - Simple chatbot for customer FAQs
   - Workflow automation connecting 2–3 tools
   - Multi-step automation across several systems
   - AI-integrated dashboard with custom logic
   - Note: No fixed prices are stated. Each project is scoped individually.

4. **How to Evaluate Whether AI Automation Is Right for Your Business**
   - Identify repetitive tasks that consume team time
   - Map existing tools and data sources
   - Define the desired outcome before choosing technology
   - Start with a workflow audit to understand scope

5. **The Estimating Process**
   - Share the workflows you want to automate
   - Describe your existing tools and systems
   - StackSpacer conducts a workflow audit during discovery
   - A project-specific estimate is provided before any commitment

6. **FAQ**
   - How long does an AI automation project take?
   - Can AI automation connect to our existing tools?
   - Do we need technical expertise to start?
   - What happens if the automation doesn't work as expected?
